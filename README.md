# VK-каталог

Стартовый проект личного сообщения бота сообщества VK с каталогом из `catalog.csv`. Реализован на Node.js + TypeScript: `vk-io` для сообщений VK, `csv-parse` для импорта и Google Sheets API для закрытого реестра оптовых клиентов.

## Что умеет стартовая версия

- Показывает категории и товары с постраничной навигацией; карточка содержит артикул, комплект, параметры и ссылку, если она есть. Из карточки можно вернуться к списку товаров, в категории или в меню.
- Не показывает оптовые цены неавторизованным клиентам. Розничная цена считается как `ceil((оптовая цена × 2,5) / 10) × 10`.
- Собирает фамилию и имя, телефон, ИНН и явное согласие в личном диалоге VK. После успешного сохранения данных в закрытой Google-таблице пользователь получает оптовый доступ.
- Хранит заявки и статус доступа в Google Sheets. Повторная регистрация по VK ID обновляет существующую строку.
- По явному запросу клиента удаляет его запись из таблицы и отключает оптовый доступ.

Это стартовая реализация, а не юридическая консультация. Перед запуском владелец должен подготовить и утвердить текст согласия и политику обработки данных, заполнить настройки и проверить соответствие применимым требованиям. Бот не публикует персональные данные в чат и не выводит их в журналы.

## Требования

- Node.js 20 или новее и npm.
- Сообщество VK с включёнными сообщениями и токеном доступа с правами на сообщения.
- Google-таблица с закрытым доступом, Google Sheets API и сервисный аккаунт, которому выдан доступ редактора к этой таблице.

## Подготовка VK и Google Sheets

1. В настройках сообщества VK включите сообщения сообщества и разрешите сообщения от пользователей.
2. В разделе «Управление → Работа с API» создайте ключ доступа сообщества с правами на работу с сообщениями (и Long Poll API). Вставьте его только в локальный `.env` как `VK_TOKEN`, а числовой ID сообщества — как `VK_GROUP_ID`.
3. В Google Cloud создайте проект, включите Google Sheets API и создайте сервисный аккаунт.
4. Создайте приватную Google-таблицу, добавьте вкладку и заголовки из следующего раздела. Поделитесь таблицей с email сервисного аккаунта, выдав ему роль редактора; не включайте общий доступ по ссылке.
5. Скопируйте JSON-ключ сервисного аккаунта в `GOOGLE_SERVICE_ACCOUNT_JSON` как компактный JSON в одну строку. Храните файл с ключом локально вне репозитория, если обрабатываете его для настройки.

Каталог и регистрация работают только в личных сообщениях сообщества: в беседах бот просит написать ему напрямую, чтобы не раскрывать персональные данные других участников.

## Установка и запуск

```sh
npm install
cp .env.example .env
```

Заполните `.env`:

- `VK_TOKEN` — токен сообщества VK (или пользовательский токен администратора для теста).
- `VK_GROUP_ID` — числовой ID сообщества; обязателен для токена сообщества, для пользовательского токена не нужен.
- `PERSONAL_DATA_CONSENT_TEXT` — утверждённый владельцем полный текст согласия. Не запускайте регистрацию с пустым или тестовым текстом.
- `PERSONAL_DATA_CONSENT_VERSION` — версия текста, например `2026-01`.
- `GOOGLE_SERVICE_ACCOUNT_JSON` — JSON сервисного аккаунта одной строкой. Не добавляйте этот файл или ключ в репозиторий.
- `GOOGLE_SPREADSHEET_ID` — идентификатор таблицы из URL.
- `GOOGLE_SHEET_NAME` — имя вкладки (по умолчанию `Clients`).
- `CATALOG_PATH` — необязательно; путь к CSV (по умолчанию `./catalog.csv`).

Создайте в приватной таблице вкладку `Clients` (или задайте другое имя) со столбцами в строке 1:

`vk_user_id | last_name | first_name | phone | inn | consent_text_version | consented_at | status`

Поделитесь таблицей только с уполномоченными сотрудниками и email сервисного аккаунта. Не включайте публичный доступ. Бот читает и обновляет этот лист; не используйте в нём иные данные.

Затем:

```sh
npm run dev
```

Для production-сборки:

```sh
npm run build
npm start
```

В VK пользователь может отправить `каталог`, чтобы начать просмотр, или `оптовые цены`, чтобы пройти регистрацию. В каталоге можно выбрать категорию, номер товара или артикул. Для регистрации бот запрашивает фамилию, имя, телефон и ИНН, затем показывает настроенный текст согласия и отдельные кнопки согласия/отказа.

## Безопасность и ограничения стартовой версии

- Доступ к таблице и JSON-ключу сервисного аккаунта ограничьте минимально необходимыми правами; храните секреты только в менеджере секретов или локальном `.env`, исключённом из Git.
- Клиент может запросить удаление данных кнопкой `Удалить мои данные`; удаление очищает его строку в Google Sheets. Владелец должен дополнительно определить политику резервных копий и процедуры обработки обращений.
- Очистка ячеек не контролирует историю версий Google Sheets и внешние резервные копии; владелец должен определить соответствующие сроки и порядок удаления.
- Состояние незавершённой регистрации хранится в памяти процесса и теряется при перезапуске. Повторная регистрация обновляет строку по VK ID, поэтому повторная доставка события не создаёт дубликат клиента.
- Обработчик ограничивает память для идентификаторов недавних событий и не обрабатывает одно и то же событие дважды в рамках процесса.
- Доступ VK к беседам и кнопкам зависит от настроек сообщества и версии VK API; перед запуском проверьте сценарий на тестовом сообществе.

## Работа с OpenCode

Файл `AGENTS.md` инструктирует OpenCode сначала читать `prompt.md`; этот промпт содержит бизнес-правила и критерии дальнейшей разработки. Запустите `opencode` из корня проекта и поручите ему выполнить задачу из `prompt.md`. OpenCode должен запрашивать недостающие решения у владельца, а не придумывать текст согласия или секреты.
